# Security policy

## Supported versions

Only the latest release of Mousam (on Flathub and the Snap Store) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/amit9838/mousam/security/advisories/new)

Include what you found, the version and how Mousam was installed (Flatpak, Snap or source), and steps to reproduce it. You will get an answer as soon as possible, and the report stays private until a fix is released.

## Scope

This policy covers Mousam's own code and its packaging in this repository. Weather data comes from [Open-Meteo](https://open-meteo.com/); problems in that service, or in GTK, libadwaita and the other libraries Mousam uses, should be reported to their own projects.
